`python3 /Users/alexlane/Developer/x-mention-watcher/scripts/autopilot_supervisor.py --config /Users/alexlane/Developer/x-mention-watcher/config.json --contract /Users/alexlane/Developer/x-mention-watcher/recovery/system-contract.json --lease-seconds 1800 relay-reserve-handoff`

Если официальный ответ не содержит projectId для Codex-задач, используй только строгий fallback: kind=codex и cwd дословно равен canonical_root из JSON; old_thread_id никогда не считай заменой. Не подменяй этот fallback совпадением title, summary или имени проекта. Если найдено больше одной замены, зафиксируй failed и заверши без создания. Если найдена ровно одна, используй её threadId и не создавай задачу. Если не найдено ни одной, вызови официальный create_thread ровно один раз: target=project с projectId из JSON и environment=local, model и thinking из JSON, prompt дословно равен initial_prompt из JSON.    - При action=update_automation или сразу после успешного created сначала дождись terminal completed новой задачи через wait_threads и официальным set_thread_title задай ей точный owner_title из JSON. Затем прочитай точный Unicode-текст `macos/x-relay.prompt.txt` и официальным automation_update обнови существующую automation `x-relay`: kind=heartbeat, name=`X: единый owner heartbeat`, status=ACTIVE, rrule=`FREQ=MINUTELY;INTERVAL=1`, notificationPolicy=failed_runs_only, targetThreadId=NEW_THREAD_ID и prompt, дословно равный файлу. Не создавай новую automation. Затем выполни `python3 scripts/browser_owner_rotation.py --config config.json --contract recovery/system-contract.json commit --rotation-token ROTATION_TOKEN`.
   - При action=commit выполни ту же команду commit с точным token. Она сама проверит automation и переключит единственный runtime-указатель.
   - После успешного commit либо при action=archive_old выполни `python3 scripts/browser_owner_rotation.py --config config.json --contract recovery/system-contract.json archive-preflight --rotation-token ROTATION_TOKEN` и требуй status=owner_rotation_archive_ready с точными OLD_THREAD_ID и NEW_THREAD_ID. Если архивный флаг ещё не виден, не создавай другую задачу: следующий heartbeat повторит только archive_old.

Не меняй config.json, TOML automation или rotation state вручную. Если новая задача уже создана, не создавай вторую: сохранённая транзакция продолжится на следующем heartbeat.

5. При route=repair выполни `python3 scripts/autopilot_supervisor.py --config config.json --contract recovery/system-contract.json --lease-seconds 1800 claim`. Если dispatch=false, освободи reservation точным token по пункту 8 и заверши. Если dispatch=true, выполни started с точным claim-token и дословно исполни prompt из claim. Если безопасный ремонт невозможен, выполни failed с точным token и причиной. Не публикуй в X и не запускай Browser без прямой необходимости ремонта.
6. При route=x сначала повтори `python3 scripts/autopilot_bridge.py --config config.json --lease-seconds 1800 gate`. Если dispatch=false, освободи reservation точным token по пункту 8 и заверши без Browser.
