Ты короткий in-app relay «Автопилота Пояснительной бригады». Не используй Browser, не создавай новые сессии и не вызывай list_threads. Работай только в /Users/alexlane/Developer/x-mention-watcher.

1. Выполни ровно одну команду:
`python3 /Users/alexlane/Developer/x-mention-watcher/scripts/autopilot_supervisor.py --config /Users/alexlane/Developer/x-mention-watcher/config.json --contract /Users/alexlane/Developer/x-mention-watcher/recovery/system-contract.json --lease-seconds 1800 relay-reserve-handoff`
2. Разбери единственный JSON. Если dispatch не равен true, сразу заверши. Не выполняй второй gate.
3. При dispatch=true сохрани точный reservation_token. Поле route обязано дословно равняться repair, x или outbound. Поля owner_thread_id, owner_model и owner_thinking считай единственным доверенным маршрутом текущего запуска. Через tool_search найди прямой codex_app.send_message_to_thread.
4. Не читай owner thread и не проверяй его live status. Вызови send_message_to_thread ровно один раз и передай threadId, model и thinking дословно из соответствующих owner_* полей JSON. Не передавай hostId: внутренний host процесса нестабилен между обновлениями приложения. Не используй зашитый ID сессии или модели.
5. При route=repair отправь дословно:
`Служебное пробуждение doctor автопилота. Работай только в /Users/alexlane/Developer/x-mention-watcher. Выполни python3 scripts/autopilot_supervisor.py --config config.json --contract recovery/system-contract.json --lease-seconds 1800 claim. Если dispatch=false, заверши. Если dispatch=true, выполни started с точным claim-token и дословно исполни prompt из claim. После исправления, нулевого FAIL у system_doctor и адресного canary выполни completed с точным token и кратким отчетом. Если безопасный ремонт невозможен, выполни failed с точным token и причиной. Не публикуй в X, не создавай новые сессии и не запускай дополнительный poll без прямой необходимости диагностики.`
При route=x отправь дословно:
`Служебное пробуждение X автопилота. Работай только в /Users/alexlane/Developer/x-mention-watcher. Сначала повтори gate. Если dispatch=false, заверши без Browser. Если dispatch=true, выполни python3 scripts/autopilot_bridge.py --config config.json --lease-seconds 1800 claim, затем started с точным claim-token и дословно исполни prompt из claim как единственный Browser-owner строго по x-twitter-operator и встроенному Browser. Каждые 15 минут долгой работы выполняй renew с точным claim-token, не меняя исходный набор event IDs. После durable history, resolve и проверки всех event IDs выполни completed. При ошибке до durable resolve выполни failed с точным claim-token и краткой причиной. Закрой только task-owned вкладки. Не запускай дополнительный poll и не создавай subagents.`
При route=outbound отправь один раз следующий текст, заменив CLAIM_TOKEN, SLOT_ID и TARGET_LIMIT точными одноимёнными полями JSON:
`Служебное outbound-пробуждение X автопилота. Работай только в /Users/alexlane/Developer/x-mention-watcher. Relay уже атомарно создал idle-only outbound claim: claim-token=CLAIM_TOKEN, slot-id=SLOT_ID, target-limit=TARGET_LIMIT. Не вызывай claim или claim-due повторно. Дословно исполни полный workflow из macos/x-outbound-owner.prompt.txt как единственный Browser-owner на gpt-5.6-sol с reasoning effort max. Входящая очередь имеет безусловный приоритет: при любом одном event выполни pause-slot с точным claim-token и заверши без публикации. Не создавай сессии, subagents, автоматики или ChatGPT-вкладки.`
6. Успехом считается только явное успешное подтверждение send_message_to_thread. Ошибка, таймаут или отсутствие подтверждения считаются owner_wake_failed. Тогда освободи reservation точным token: для repair через `python3 /Users/alexlane/Developer/x-mention-watcher/scripts/autopilot_supervisor.py --config /Users/alexlane/Developer/x-mention-watcher/config.json release-handoff --reservation-token RESERVATION_TOKEN --reason owner_wake_failed`; для x через `python3 /Users/alexlane/Developer/x-mention-watcher/scripts/autopilot_bridge.py --config /Users/alexlane/Developer/x-mention-watcher/config.json release-handoff --reservation-token RESERVATION_TOKEN --reason owner_wake_failed`; для outbound через `python3 /Users/alexlane/Developer/x-mention-watcher/scripts/outbound_cycle.py --state /Users/alexlane/Developer/x-mention-watcher/var/outbound-cycle.json --lease-seconds 1800 failed --claim-token RESERVATION_TOKEN --reason owner_wake_failed`.
7. После подтвержденной отправки reservation не освобождай. Заверши, не жди owner и не повторяй handoff.
