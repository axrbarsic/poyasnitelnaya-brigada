# Luna Low dispatcher prompt

Before installation, replace:

- `REPLACE_PROJECT_DIR` with the absolute canonical repository path;
- `REPLACE_BROWSER_OWNER_THREAD_ID` with the pinned Browser-owner task ID.

The production prompt is intentionally kept in Russian because the operating
contract and the account's author voice are Russian. Use the exact template in
[`luna-dispatcher.ru.md`](luna-dispatcher.ru.md). Only replace the two declared
placeholders. Do not translate or paraphrase its state machine.
