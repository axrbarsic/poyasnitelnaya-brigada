# Контроль стоимости X API

## Рабочий контракт

Автопилот использует два независимых маршрута чтения:

1. `GET /2/users/:id/mentions` проверяет собственные упоминания раз в минуту.
   Этот маршрут всегда остается включенным.
2. Recent Search проверяет боковые ответы в уже сохраненных цепочках, где
   `@axrbarsic` мог не повториться. Это страхующая, более дорогая функция.

Оба маршрута запрашивают только поля Post. Они не используют `expansions`,
`user.fields` или `media.fields`. Имя автора и содержимое медиа проверяются в
точном статусе встроенным Browser только после появления события в очереди.

## Бюджетный предохранитель

Recent Search запускается раз в пять минут и ограничен двумя параметрами:

- `conversation_tail_daily_post_read_limit`: максимум возвращенных Post за
  сутки UTC, по умолчанию 200;
- `conversation_tail_max_post_reads_per_poll`: максимум за один запуск, по
  умолчанию 50.

При общем тарифе чтения Post это ограничивает страхующий поиск суммой до
1 доллара в сутки. Фактическая сумма может быть ниже из-за дневной
дедупликации X. Собственные упоминания не входят в этот локальный лимит и не
останавливаются при его исчерпании.

Большой проход сохраняет в SQLite номер query и точный pagination token X.
Следующий запуск продолжает с нужной страницы. Курсор успешного tail меняется
только после полного прохода, поэтому частичная обработка не создает дырку во
времени.

Проверка состояния:

```bash
python3 xmention_watcher.py --config config.json status
```

В `x_api_budget.conversation_tail` видны лимит, использованные Post, остаток и
число запросов текущих суток UTC. Таблица `poll_runs` отдельно хранит число
возвращенных ресурсов и HTTP-запросов каждого прохода.

## Следующий этап: Account Activity API

Правильная долгосрочная архитектура для мгновенной доставки состоит из
Account Activity webhook и дешевого mentions poll как аварийной страховки.
Webhook устраняет постоянный широкий поиск и сообщает об изменениях аккаунта в
реальном времени. Для включения нужны публичный HTTPS endpoint, CRC-проверка,
OAuth-подписка пользователя и секрет подписи. До развертывания необходимо
отдельно подтвердить домен размещения и пройти OAuth, поэтому текущий код не
создает внешнюю инфраструктуру автоматически.

Официальные источники:

- [X API pay-per-use pricing](https://docs.x.com/x-api/getting-started/pricing)
- [Account Activity API](https://docs.x.com/x-api/account-activity/introduction)
